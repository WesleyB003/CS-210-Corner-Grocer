# CS-210 Project Three: Corner Grocer

## Project Summary

For this project, I created a C++ program that helps a grocery store track how often different items are purchased. The program reads information from a file, counts the frequency of each item, and allows users to search for specific products. It can also display a complete list of item frequencies or a histogram. The goal was to make it easier for the store to understand customer purchasing habits.

## What I Did Well

I think I did a good job organizing the program and making the menu easy to understand. I also worked on keeping the code readable by using functions for different tasks instead of putting everything in one place. Getting the program to display the correct item counts was something I was particularly happy with.

## Areas for Improvement

One improvement I could make would be adding better error handling for situations where files cannot be opened or users enter unexpected information. I could also improve how the program handles larger amounts of data. These changes would make the program more reliable and easier to use.

## Challenges and Resources

The most challenging part was working with file input and making sure the program counted each item correctly. I had to spend time understanding how the data was being stored and retrieved. Testing different parts of the program helped me identify mistakes. I also used course materials, programming examples, and online C++ documentation to better understand concepts I was struggling with.

## Transferable Skills

One of the biggest skills I gained was learning how to organize a C++ program using functions and data structures. I also became more comfortable reading files, processing information, and troubleshooting errors. These are skills I can use in future programming courses and software development projects.

## Maintainability and Readability

I tried to make my program maintainable by using descriptive variable names, separating tasks into functions, and including comments where needed. Keeping the code organized makes it easier to understand and update later. If I wanted to add more features in the future, I would have a better starting point instead of having to rewrite the entire program.
